# w4ghsIPscan

> Advanced IP address scanner: WHOIS, port scanning, leak detection, reverse IP lookup, and availability check using Check-Host.

---

##  Features

| Module | Description | Source |
|--------|-------------|--------|
| 🌐 **IP API** | Geolocation, ISP, ASN | ip-api |
| 🚪 **Port Scan** | Scanning of popular ports | local |
| 🩸 **Leak Check** | Search for IP/domain in public leaks | leakcheck,proxynova |
| 🔁 **Reverse IP** | Reverse domain lookup by IP | hackertarget |
| 📡 **Ping Check** | Availability check from worldwide nodes | check-host.net |
| 🧭 **DNS Check** | Domain resolution from different locations | check-host.net |
| ✅ **IP Validation** | IPv4/IPv6 validation | ipaddress |
